# Общие правила работы со мной

## Язык общения

- Всегда отвечай мне на русском языке, если я явно не попросил другой язык.
- Объясняй простыми словами, как новичку.
- Не используй сложные термины без объяснения.

## Мой уровень

- Я новичок в программировании.
- Не предполагаю, что я хорошо знаю архитектуру, паттерны, терминал, Git или устройство движка.
- Если предлагаешь команду терминала, объясни, где её запускать.
- Если предлагаешь действие в интерфейсе программы, пиши пошагово: что нажать, где искать, что должно получиться.

## Стиль разработки

- Работай маленькими шагами.
- Не переписывай весь проект без необходимости.
- Сначала предложи план, потом вноси изменения.
- После каждого изменения объясняй, что изменилось и как проверить.
- Предпочитай простые решения сложным.
- Не добавляй архитектуру “на будущее”, если она не нужна прямо сейчас.
- Не создавай много новых файлов без причины.
- Если можно исправить 5 строками, не переписывай 200 строк.

## Правила безопасности кода

- Перед крупными изменениями напомни сделать git commit.
- Если меняешь несколько файлов, в конце дай список изменённых файлов.
- Если есть риск сломать проект, сначала предупреди.
- Не удаляй файлы без явного подтверждения.
- Не меняй настройки проекта без объяснения причины.

## Формат ответов

- В начале кратко скажи, что будешь делать.
- Затем дай конкретные шаги.
- Код давай целиком для изменяемой функции или файла, если это проще для копирования.
- После кода дай инструкцию, как проверить результат.
- Если появилась ошибка, сначала помоги её понять, потом исправляй.

## Работа с ошибками

- Когда я присылаю ошибку, сначала объясни простыми словами, что она означает.
- Затем предложи минимальное исправление.
- Не предлагай сразу полную переделку архитектуры.
- Если информации недостаточно, попроси конкретный файл, сцену или текст ошибки.

## Git

- Напоминай делать коммит после каждого стабильного этапа.
- Сообщения коммитов пиши коротко и понятно на английском.
- Не выполняй опасные команды Git без моего подтверждения.
- Особенно не используй reset --hard, clean -fd, rebase, force push без явного разрешения.
