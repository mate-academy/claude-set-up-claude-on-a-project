- Команди: `npm run dev`, `npm test`, `npm run lint`
- Конвенції: використовуємо async/await, не використовуємо var
- Архітектура: server.js → routes/ → db/store.js


**Що свідомо виключив:**

- Чутливі дані (.env) — небезпечно
- Одноразові нотатки — CLAUDE.md для постійних правил


## Permissions
**Дозволені (allow):**
- `Bash(npm test:*)` — безпечно запускати тести


**Запит (ask):**
- `Bash(git push:*)` — хочу підтвердження перед пушем


**Заборонені (deny):**
- `Read(./.env)` — там секрети
- `Bash(git push --force:*)` — небезпечно перезаписати історію


**Що могло піти не так без deny:**
- Випадковий доступ до .env — витік паролів/ключів
- Force push — втрата історії комітів
